# EEmployeeHub - Local Storage Edition

A simple Employee Management System using only:
- HTML
- CSS
- JavaScript
- Browser Local Storage

No Docker, Spring Boot, MySQL, Java, or backend server is required.

## Features
- Dashboard
- Total employee count
- IT / HR / Finance department counts
- Add employee
- Edit employee
- Delete employee
- Search employees
- Filter by department
- Local Storage persistence
- Clear all data
- Responsive layout

## Run
Open `index.html` in a browser.

For VS Code, you can also use the Live Server extension.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the repository root and enable GitHub Pages.

Important: Local Storage data belongs to each browser/device. It is not a shared online database.
